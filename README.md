# embedded-notes

嵌入式硬件方向的学习笔记与课程实验代码。

重庆邮电大学 · 电子信息工程 · 本科在读

## 内容组织

```
├── notes/          学习笔记（原理梳理、踩坑记录）
├── labs/           课程实验代码（模电、单片机、嵌入式系统）
└── projects/       课外练习与小项目
```

## 记录什么

- **原理理解**：把书上看懂的东西用自己的话写一遍，写不出来就是没懂
- **调试过程**：报错信息、排查思路、最后怎么解决的——这部分比正确代码更值钱
- **实验数据**：示波器波形、测量值、参数对比

## 环境

- 开发工具：Keil MDK / STM32CubeIDE / VS Code + PlatformIO
- 版本管理：Git
- 硬件平台：STM32F103 / 51 单片机
